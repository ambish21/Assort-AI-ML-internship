## CLI Student Management System

A Python-based CLI application to manage student records using OOP, Functions, File Handling, and JSON.

## Concepts Used:
OOP (Class, Objects, Constructor, Methods)
Functions for different operations
List handling for storing student objects
Input Validation to prevent invalid data
Duplicate Roll Number Checking
CRUD Operations (Add, View, Search, Update, Delete)
File Handling for permanent data storage
JSON for saving and loading records
Menu Driven Application using while loop and match-case
## Features:

✅ Add Student
✅ View Students
✅ Search Student by Roll Number
✅ Update Student Record
✅ Delete Student Record
✅ Save & Load JSON Data
✅ Error Handling & Validation

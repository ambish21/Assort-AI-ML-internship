### shorts notes 

### Password Hashing
Converts a password into a secure hash so the original password is not stored directly.

### bcrypt
A password-hashing algorithm designed to securely hash passwords.

### Passlib
A Python library that provides password hashing and verification tools.

### JWT (JSON Web Token)
A token used to securely identify/authenticate a user between the client and server.

### Secret Key
A private key used to sign and verify JWT tokens.

### Access Token
A JWT given to a user after successful login and used to access protected APIs.

### Protected Route
An API endpoint that requires a valid authentication token.

### Password Verification
Checks whether a plain password matches the stored hashed password.

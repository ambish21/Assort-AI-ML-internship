## Practical

Built a FastAPI Authentication API with:

* User registration
* Secure password hashing
* Login authentication
* JWT access token generation
* JWT token validation
* Protected API route
* Wrong password handling
* Swagger API testing

## Endpoints

* `GET /` — Home
* `POST /register` — Register user and hash password
* `POST /login` — Verify password and generate JWT
* `GET /protected` — Access protected data using JWT

### REST API

An API that follows REST principles and uses HTTP methods to communicate between client and server.

### HTTP Methods

* **GET** → Retrieve data
* **POST** → Create/send new data

### JSON

A lightweight data format commonly used for sending and receiving API data.

### Request/Response

**Client → Request → Server → Response → Client**

### FastAPI

A modern Python framework for building fast REST APIs.

### Uvicorn

An ASGI server used to run FastAPI applications.

### Student API

Created a basic API with **GET** and **POST** endpoints for student data.

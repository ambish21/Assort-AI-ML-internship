# Day 23 — Pydantic Models

## Topics

* Pydantic Models
* Request Validation
* Response Models
* Type Checking

## Practical

Created an Employee API using FastAPI and Pydantic.

### Features

* Employee data validation
* Type checking
* Name, age, salary and email validation
* Add employee endpoint
* Tested valid and invalid employee data
* Tested API using Swagger UI

## Technologies

* Python
* FastAPI
* Pydantic
* Uvicorn

## Testing

The API was tested through FastAPI Swagger UI.

* Valid employee data → Successful response
* Invalid employee data → Validation Error (422)

## Learning Outcome

Learned how Pydantic models provide structured data validation and type checking in FastAPI.

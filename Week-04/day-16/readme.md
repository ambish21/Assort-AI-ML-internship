- Students — 100 records
- Employees — 100 records
- Products — 100 records

## How It Works

1. `seed_data.py` connects Python with MongoDB using PyMongo.
2. Sample student, employee and product data is created.
3. `insert_many()` inserts 100 documents into each collection.
4. MongoDB Compass is used to view the inserted data.

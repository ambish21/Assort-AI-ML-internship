# Day 19 - Product Search Engine

## Overview

Built a Product Search Engine using Python and MongoDB.

## Features

- Search products using regex
- Filter products by category
- Filter products by price
- Sort products by price
- Pagination
- Show discounted products
- Exclude categories

## MongoDB Concepts

- $in
- $nin
- $exists
- $regex
- Projection
- Sorting
- Pagination
- skip()
- limit()

## Technologies

- Python
- PyMongo
- MongoDB

## Run

Install dependencies:

pip install -r requirements.txt

Seed products:

python seed_products.py

Run application:

python main.py

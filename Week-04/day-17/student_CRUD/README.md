

# Student Database CRUD System

## Overview

This project demonstrates MongoDB CRUD operations
using Python and PyMongo.

## CRUD Operations

Create:
- insert_one()
- insert_many()

Read:
- find()

Update:
- update_one()
- update_many()

Delete:
- delete_one()
- delete_many()

## Technologies

- Python
- MongoDB
- PyMongo
- python-dotenv

## How to Run

1. Install dependencies
2. Configure MONGO_URI
3. Run main.py

## Learning Outcomes

- MongoDB CRUD
- PyMongo
- Collections and documents
- Query filters
- Update operators
- MongoDB results

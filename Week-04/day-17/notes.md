Day 17 — MongoDB CRUD Operations | Short Notes

CRUD stands for Create, Read, Update, and Delete.

Create: insert_one() inserts one document, while insert_many() inserts multiple documents.

Read: find() retrieves documents from a collection.

Update: update_one() updates one document, while update_many() updates multiple documents.

$set is used to change or update a field value.

Delete: delete_one() deletes one document, while delete_many() deletes multiple documents.

PyMongo is used to connect Python with MongoDB.

.env stores the MongoDB connection URI securely.

MongoDB Compass was used to verify and view the database records.

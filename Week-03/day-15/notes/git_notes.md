# Git Notes

## What is Git?

Git is a Version Control System (VCS) that tracks changes in files and source code.

## Why Git?

- Tracks project history
- Restores previous versions
- Enables teamwork
- Prevents data loss

## Git Workflow

Working Directory
↓
Staging Area
↓
Local Repository
↓
GitHub

## Important Commands

git init
git status
git add .
git commit -m "message"
git push
git pull
git clone
git branch
git switch
git merge

## Branch

A separate copy of your code used to develop new features safely.

## Merge

Combines one branch into another.

## Pull Request

A request to merge code after review.

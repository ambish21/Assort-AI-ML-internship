# Secure Banking Application

## Description

A Python console-based banking system that allows users to:

- Deposit Money
- Withdraw Money
- Check Balance
- Handle Invalid Inputs
- Prevent Invalid Transactions
- Use Custom Exceptions
- Demonstrate Exception Handling

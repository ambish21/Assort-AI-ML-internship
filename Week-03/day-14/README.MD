# Secure Banking Application (Refactored)

## Overview

This project is a menu-driven Secure Banking System developed in Python.

The application allows users to create accounts, deposit money, withdraw money, transfer funds, check balances, display all accounts, and delete accounts.

The project is refactored using Python Logging and Debugging concepts.

---

## Features

- Create Account
- Deposit Money
- Withdraw Money
- Transfer Money
- Check Balance
- Display All Accounts
- Delete Account
- JSON Data Storage
- Exception Handling
- Logging
- Error Tracking
- Debug Reports
